# Fundy — catálogo

Esta es la primera versión del catálogo de Fundy con 5 fundas de iPhone 15.

## Para agregar productos
Abrí `products.js` y copiá uno de los objetos existentes. Cambiá:
- name
- model
- price
- image

Las fotos nuevas deben ir dentro de la carpeta `images`.

## WhatsApp
En `script.js`, reemplazá `549XXXXXXXXXX` por el número de WhatsApp de Fundy, sin `+`, espacios ni guiones.

## Publicar en Vercel
Podés subir esta carpeta a GitHub y luego importarla en Vercel. No requiere servidor ni base de datos: es un sitio estático.
